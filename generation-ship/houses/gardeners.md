# House Gardeners, the Greenkeepers

**Template:** A Spread of Rampant Green · **Curve:** standard (1.82)

They spread influence fast and turn it into living armor: Decay that would land on them takes their influence instead.

- **Guilds:** Farmers (primary, 1 PP) / Scholars (secondary, 1.5 PP)
- **Weaknesses:** Rooted spends influence, and a house with no influence loses the game for everyone. Weak direct damage.

## Tracks
The first value is the starting value. ★ marks a special slot.

| Track | Values |
|---|---|
| Credits per generation | 1 → 1 → 2 → ★ +Farmers → 3 → 5 |
| Card plays | 2 → 2 → 2 → 3 → ★ +1 clone slot → 4 |

Hand = plays + 2. Clone 1.

## Special rule
When Decay would be placed in a section with Gardener influence, remove 1 Gardener influence there instead.
- *Estimated value:* ≈ 1.5 PP per generation.
