# ChatGPT-ready image prompts

Copy each block as one message: one block = one image.

- **New chat per style.** Start a new ChatGPT chat for each style.
- **Opener first.** Send the style's **opener** message, then the prompts in order.
- **Iterate on the first portrait.** Get Ostra Vell right before moving on; she becomes the style anchor for that chat.

Save results to `generation-ship/art/source/<style>/` using the file name shown above each prompt.

**Starting a second, third or fourth style.** In the new chat, upload your favourite Ostra image from the earlier style and add this line to the start of that style's Ostra prompt:

> Same woman as the attached image: same face, age, hair and pose. Repaint her completely in the style below.

Do the same for Dace, Ilka and Pell once you have a favourite of each.

## Tips
- **If text sneaks in,** reply: "Same image, but remove all text and lettering."
- **If the face sits too low** for the card window, reply: "Same image, but zoom out slightly and move her face higher, with more space above and around the head."
- **If board A gets too busy,** reply: "Same layout, but simplify: calmer room floors, fewer props, stronger colour difference between room types."
- **Minimum first pass:** `ostra.png` and `board_a.png` for each style, 8 images in total.
