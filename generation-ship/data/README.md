## People cards

`people.json` and `people.csv` are generated by [`../tools/generate_people.py`](../tools/generate_people.py) from the GDD's Balance framework. **Don't hand-edit them.** Change the generator (prices, pools, counts) and re-run it:

```
python3 tools/generate_people.py
```

The generator is deterministic (seed 1), so re-running it reproduces the same deck.

## The deck: 400 people cards

| | Common | Remarkable |
|---|---|---|
| Count | 300 | 100 |
| Credit cost | 0–3 | 2–8 |
| Card value (PP) | 2 + cost | 2 + 1.5 × cost |
| Effect types per card | up to 2 | up to 3 |
| Element threshold bonus | ~21% of cards (64) | every card |
| Reign − Legacy | +1 PP | +2 PP |

- **Guild icons:** 2–4 different guilds per card, 3.0 on average. Each guild appears on about 150 cards.
- **PP accuracy:** every card's effect lands within ±0.25 PP of its target value.

## How a card is built
1. **Guilds.** Icons come from a balanced pool. The first icon is the card's *primary* guild, which sets its effect tendencies and home section type.
2. **Cost and target value.** Pick a cost (weighted), then compute the target PP.
3. **Target.** Most cards target a section: range 0–3 from influence, aimed at ANY, the primary guild's home type, or a narrow condition. About 7% target **another house** (credits, influence or Purpose).
4. **Effects.** Fill effects from the primary guild's pool (the secondary guild at half weight) until the modified PP hits the target. Range and target modifiers apply only to section effects. Global effects (Purpose, credits, foresee, temper) aren't modified.
5. **Threshold bonus.**
   - The requirement is 2–3 elements on Commons and 3–6 on Remarkables, drawn from the card's own primary and secondary guilds.
   - The bonus is worth **1 PP per required element**.
6. **Reign and Legacy.**
   - **Reign** applies at the start of Day. **Legacy** applies at Dusk in each section matching the paired event.
   - Effects that act per section are priced at **2 reference sections**. Credits for each house are priced at **2 houses**.
   - **Legacy prices:**

| Legacy effect | PP |
|---|---|
| Add Glitch / Fault / Failure | 1 / 2 / 3 |
| Destroy Crew | 3 |
| Add Decay | 4 |
| Each house loses 1 influence | 2 |
| Add Unrest | 1.5 |
| −1 Purpose | 1 |
| Each house loses 1 credit | 1 |

## Known limitations (for calibration)
- **Effects in a card's text all hit the one targeted section.** There's no split targeting yet.
- **Reign and Legacy are priced at fixed reference counts**, not the real number of matching sections.
- **Expensive effects are over-represented.** Add Crew (3 PP) fits budgets easily, so it's common (43 cards). Vent Failure and Quarantine are rare.
- **The deck has no names or flavor**, by request. Cards are identified by ID only (`C001`–`C300`, `R001`–`R100`).

## Events (`events.json`)

| Stage | Pool | Dealt | Content |
|---|---|---|---|
| I | 4 | 3 | One section type each |
| II | 5 | 4 | One type each, with a twist; plus one **Outer Hull** card (no twist) |
| III | 6 | 5 | Every pair of section types |

**Stage II twists:**
- **Infrastructure, Power surge:** at Collapse, each Fault deals +1 damage.
- **Residential, Panic:** at Collapse, destroy 1 additional Crew in each matching section with threat.
- **Government, Red tape:** at Grow, each matching section that gains a Fault also gains a Glitch.
- **Agricultural, Spreading rot:** at Seed, also seed each section adjacent to a matching section with threat.

**Escalation:** after dealing Stage II, one random dealt Stage II card is marked with the Escalation symbol.

**Landfall:** set aside; matches every section.

## Discoveries (`discoveries.json`)

- **24 cards**, 6 in each of four families: **Repair, Control, Protection, People**.
- **One-time tier effects** are worth **4 / 6 / 8 PP** at Understanding I / II / III. They apply to each section of one scope (a section type or the Outer Hull), priced at 2 reference sections.
- **Breakthroughs** are worth about **1 PP per generation**: a small effect each Dawn, Day or Dusk in one section of a scope, chosen by the players.

## Ship in Crisis (`crisis.json`)

One card is picked at random during setup. When it flips, add 1 Decay per player to the pool.

| Card | Effect |
|---|---|
| **X1 Rationing** | At the start of each Day, each house loses 1 credit. |
| **X2 Structural Fatigue** | Each cascade places 2 Decay instead of 1. |
| **X3 Despair** | Each time Decay is placed, lose 1 Purpose. |
| **X4 Failing Systems** | At each Grow, add 1 Glitch to every section with Decay and no threat. |

## Boards (`boards.json`)

Generated by [`../tools/generate_boards.py`](../tools/generate_boards.py).

- **One shared outline:** a hexagonal hull module (circumradius 180, centred on 0,0).
  - **Side 4 (the top)** is the Outer Hull: faceted plating, a prow and two fins.
  - **Sides 0–3 and 5** dock: each has the same point-symmetric dovetail clamp and socket, so any docking side mates with any other.
- **Four interiors (A–D):** each has 8 Voronoi sections (2 of each type) with angular borders. Each section stores its polygon, its centre, its adjacency, and which board sides it touches (with the parameter range along each side).
- **Layouts** place boards on a hex grid as `[x, y, rotation]`:
  - available layouts: solo, pair, line3, arc3, triad, line4, diamond, arc4, fan;
  - rotations keep each Hull facing the void and maximize the number of docking links;
  - `links` lists the cross-board adjacencies;
  - `default_layout` picks one per player count.
- **Setup per board:**
  - 1 Failure, 2 Faults and 1 Glitch, each in a different section type (the Failure's type rotates between boards),
  - 1 Decay next to the Failure (not from the pool),
  - 6 Crew (2, 2, 1, 1) across 4 sections away from the Failure and Decay.

## Houses (`houses.json`)

The data version of `houses/*.md`: tracks, special rules, innate tiers, growth options and starting-influence rules.
- Innate tiers list their **full cumulative effect**; use the highest tier met.
- In tracks, the first value is the starting value. Object entries are special slots.
