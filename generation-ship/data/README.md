# Generated card data

`people.json` and `people.csv` are generated by [`../tools/generate_people.py`](../tools/generate_people.py) from the GDD's Balance framework. **Don't hand-edit them.** Change the generator (prices, pools, counts) and re-run it:

```
python3 tools/generate_people.py
```

The generator is deterministic (seed 1), so re-running it reproduces the same deck.

## The deck: 400 people cards

| | Common | Remarkable |
|---|---|---|
| Count | 300 | 100 |
| Credit cost | 0–3 | 2–8 |
| Card value (PP) | 2 + cost | 2 + 1.5 × cost |
| Effect types per card | up to 2 | up to 3 |
| Element threshold bonus | ~21% of cards (64) | every card |
| Reign − Legacy | +1 PP | +2 PP |

- **Guild icons:** 2–4 different guilds per card, 3.0 on average. Each guild appears on about 150 cards.
- **PP accuracy:** every card's effect lands within ±0.25 PP of its target value.

## How a card is built
1. **Guilds.** Icons come from a balanced pool. The first icon is the card's *primary* guild, which sets its effect tendencies and home section type.
2. **Cost and target value.** Pick a cost (weighted), then compute the target PP.
3. **Target.** Most cards target a section: range 0–3 from influence, aimed at ANY, the primary guild's home type, or a narrow condition. About 7% target **another house** (credits, influence or Purpose).
4. **Effects.** Fill effects from the primary guild's pool (the secondary guild at half weight) until the modified PP hits the target. Range and target modifiers apply only to section effects. Global effects (Purpose, credits, foresee, temper) aren't modified.
5. **Threshold bonus.**
   - The requirement is 2–3 elements on Commons and 3–6 on Remarkables, drawn from the card's own primary and secondary guilds.
   - The bonus is worth **1 PP per required element**.
6. **Reign and Legacy.**
   - **Reign** applies at the start of Day. **Legacy** applies at Dusk in each section matching the paired event.
   - Effects that act per section are priced at **2 reference sections**. Credits for each house are priced at **2 houses**.
   - **Legacy prices:**

| Legacy effect | PP |
|---|---|
| Add Glitch / Fault / Failure | 1 / 2 / 3 |
| Destroy Crew | 3 |
| Add Decay | 4 |
| Each house loses 1 influence | 2 |
| Add Unrest | 1.5 |
| −1 Purpose | 1 |
| Each house loses 1 credit | 1 |

## Known limitations (for calibration)
- **Effects in a card's text all hit the one targeted section.** There's no split targeting yet.
- **Reign and Legacy are priced at fixed reference counts**, not the real number of matching sections.
- **Expensive effects are over-represented.** Add Crew (3 PP) fits budgets easily, so it's common (43 cards). Vent Failure and Quarantine are rare.
- **The deck has no names or flavor**, by request. Cards are identified by ID only (`C001`–`C300`, `R001`–`R100`).
